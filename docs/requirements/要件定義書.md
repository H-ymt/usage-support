## 1. 背景・目的

### 1.1 背景
- LP経由で流入した見込み顧客を、継続的にフォロー可能なLINE上で管理する必要がある
- 店頭での貸出開始日登録において、入力ミスや認識ズレが発生しやすい
- 90日間の貸出期間中におけるアンケート未回答・来店未実施による離脱が課題となっている

### 1.2 目的
- LP → LINE友だち追加 → LINEミニアプリ利用までの一貫した体験を提供する
- 店頭での貸出開始日を「登録当日固定」とし、運用ミスを技術的に防止する
- 90日間の進行状況を可視化し、通知・アンケート・予約により継続利用を促進する

## 2. システム構成・前提

### 2.1 採用技術スタック

| 区分 | 技術 |
|---|---|
| フロントエンド | Next.js（OpenNext / Cloudflare Workers） |
| BFF / API | Cloudflare Workers |
| データベース | Supabase（PostgreSQL） |
| 認証（ユーザー） | LINE LIFF認証 |
| 認証（管理者） | Supabase Auth（メール/パスワード） |
| 利用形態 | LINEミニアプリ（LIFF） |

### 2.2 アーキテクチャ方針

- 業務ルール・日付確定・状態遷移はすべてCloudflare Workersで実施する
- フロントエンドは表示・入力補助のみを担当し、業務判定は行わない
- クライアント時刻・入力日付は一切信用しない
- タイムゾーンはJST（Asia/Tokyo）を基準とする

## 6. 機能要件（ユーザー向け）

### 6.1 基本情報登録

- 氏名：必須
- 電話番号：必須
- メールアドレス：必須／任意（※運用決定事項）
- LINEユーザー識別子（user_key）と紐づけて保存する
- 基本情報未登録の場合、貸出開始登録は不可とする

---

### 6.2 ダッシュボード（90日管理）

#### 表示内容

- 貸出ステータス
  - 未開始 / 進行中 / 終了
- 進行中の場合
  - 残日数
  - 返却予定日（開始日 + 90日）
  - 次回アンケート案内（未回答時は強調表示）
  - 次回予約情報

---

### 6.3 使用状況アンケート

#### 6.3.1 基本仕様

- 実施タイミング：開始日から30日 / 60日 / 90日
- LINEミニアプリ内フォームで回答
- 回答履歴を保持する
- 未回答アンケートはダッシュボード上で明示する

#### 6.3.2 設問サンプル

**30日アンケート（初期適応確認）**

| # | 設問 | 回答形式 |
|---|---|---|

| 2 | 1日あたりの平均装着時間を教えてください | 単一選択（8時間以上 / 4〜8時間 / 4時間未満） |
| 3 | 音の聞こえ方に満足していますか？ | 5段階評価（1:不満 〜 5:満足） |
| 4 | 装着時に違和感はありますか？ | 単一選択（なし / 少しある / かなりある） |
| 5 | 困っていることがあればお聞かせください | 自由記述（任意） |

**60日アンケート（中間評価）**

| # | 設問 | 回答形式 |
|---|---|---|
| 1 | 補聴器の使用を継続していますか？ | 単一選択（毎日 / 週に数回 / ほとんど使っていない） |
| 2 | 会話が聞き取りやすくなりましたか？ | 5段階評価（1:変わらない 〜 5:とても良くなった） |
| 3 | 外出時に使用していますか？ | 単一選択（常に / 時々 / 使っていない） |

| # | 設問 | 回答形式 |
|---|---|---|

## 7. 店頭 貸出開始登録要件（当日固定）

### 7.1 基本ルール

- 貸出開始日は必ず「登録当日」とする
- 日付の入力・選択は不可とする
- サーバー側（Cloudflare Workers）の日時を正とする

---

### 7.2 登録方法

- 店頭に貸出開始登録用QRコードを設置する
- ユーザーがLINEミニアプリでQRコードを読み取る
- 「本日から貸出開始」の確認画面を表示する
- 確定後、自動的に以下を設定する
  - 開始日：当日
  - 終了日：開始日 + 90日

---

### 7.3 ガード条件

- ユーザー基本情報未登録の場合は登録不可
- 既に進行中の貸出が存在する場合は登録不可
- QRコードはトークン化し、改ざん・使い回しを防止する

#### 7.3.1 QRトークン仕様（概要）

- 店舗ごとに発行される一意のトークンをQRコードに埋め込む
- トークンには有効期限を設定（例：24時間）
- 使用済みトークンは再利用不可
- トークンは管理画面から再発行可能

## 13. 運用ルール（要決定事項）

以下の項目は運用開始前に決定が必要：

| 項目 | 検討内容 | 決定状況 |
|---|---|---|
| 終了日が休業日の場合 | 前倒し or 後ろ倒し or そのまま | 未定 |
| アンケート回答可能期間 | 該当日から何日間有効か | 未定 |
| 予約変更・キャンセル締切 | 予約日の何時間前まで可能か | 未定 |
| 本人確認方法 | 電話番号・メールの確認要否 | 未定 |
| QRトークン有効期限 | デフォルトの有効時間 | 未定 |

## 14. 受け入れ基準

- 店頭QRから開始登録した場合、開始日が必ず当日になること
- 開始日から90日後が正しく終了日として表示されること
- 30 / 60 / 90日でアンケート導線が表示され、回答が保存されること
- 予約の作成・変更・キャンセルが正しく反映されること
- 管理画面にメール/パスワードでログインできること
- ユーザー検索・詳細閲覧が正しく動作すること
